Golf Games Privacy Policy

Effective October 2026 · © 2026 James Hable. All rights reserved.

Golf Games does not sell or share your personal data, and does not track you. There are no accounts, no ads and no analytics.

What stays on your phone

Games, scores, saved players, phone numbers and stats are stored only on your phone. Deleting the app deletes them.

Phone numbers

Phone numbers you enter are used only to fill in a text message that you send yourself from the Messages app. They are never uploaded or shared.

Location

If you tap Courses Near Me, the app asks for permission to use your location once, to list golf courses within 3 miles. The search runs on your phone against a course list built into the app. Your location is never sent anywhere.

Course search

If you search for a course by name, the name you type is sent to OpenGolfAPI (opengolfapi.org), a free public golf course directory, to look up the course's pars. Nothing else is sent.

Live Scoreboard

If you choose to share a game live, it is encrypted on your phone before it is stored in Apple iCloud. Only people with the game code or link you send can read it; neither Apple nor the app's developer can. (Lock Screen updates for followers are the one exception; see below.) Phone numbers are removed before a game is shared. Shared games are deleted when you stop sharing, delete the game, or 48 hours after the last update.

Lock Screen live updates

When a game is shared live, the scorer's phone sends the current standings (player names, scores and the latest hole) to the Golf Games push server, which passes them to Apple's push service to update followers' Lock Screens and Dynamic Island. The server keeps followers' push addresses for 3 days so it can reach them, and does not store the standings. Games are identified by a hash of the game code, never the code itself. Phone numbers are never sent.

Children

The app does not knowingly collect any information from anyone, including children.

Changes and contact

If this policy changes, the new version will be posted here. Questions: see the support page.
